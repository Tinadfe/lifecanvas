# 人生目标具象画 v0.2

> 一个**只属于你、完全离线、图片+文字**的人生愿景与正念工具。
> 把"未来自己的样子"和"理想生活的场景"变成每天打开就能看见的画面，
> 用每日正念仪式、愿望回看、奖励打卡，让目标每天靠近一点。
> **数据只在你自己的设备里**——无账号、无云端、无统计、无第三方 SDK。
> v0.2 新增：**内置 AI 生图工坊**（一键生成未来形象与愿景场景）。

---

## 一、功能一览（六个模块）

| 模块 | 做什么 |
|------|--------|
| 🏠 今日 | 每天第一眼看到"未来形象图" + 今日正念 + 今日愿望回看 + 进度统计 |
| 🪞 形象 | 形象卡（发型/神态/气质/穿着）→ 自动拼成 AI 生图提示词；上传真实照片与榜样参考图；导入生成的未来形象图并设为每日主形象 |
| 🖼 愿景 | 理想生活场景画廊（我的家/爱好角落/父母的晚年/我的孩子/我的工作/我的旅行），每图配一句话愿景 |
| 🌿 正念 | 场景化仪式：起床感恩、喝水感受、慢食感恩、行动前心理建设、睡前三件感恩；内置语句库 + 自定义 |
| ⭐ 愿望 | 短期/中期/长期愿望，每日回看打卡；实现后记录"鲜花之后的感受" |
| 📖 记录 | 今日体验 + 三件感恩 + 心情指数 + 配图；小目标奖励打卡（奖励/感受/过程）；成就与连续记录 |

另含：**口令加密**（愿望与日记 AES-256 加密）、**一键备份**（.lvpack 压缩包 / 自包含 HTML 快照）。

## 二、快速开始（本机预览）

方法 A：直接双击 `index.html`（Safari/Chrome 均可，离线可用；注意 file:// 下加密功能可能不可用）。

方法 B：起本地服务（推荐，加密可用）：
```bash
cd lifecanvas
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

---

## 三、部署到 GitHub Pages（路径 A，推荐，0 元）

> 你的数据永远只存设备本地，GitHub 只是"送货上门"的静态托管，看不到你的任何内容。

1. 在 GitHub 新建一个仓库（如 `lifecanvas`，公开或私有均可）
2. 把 `lifecanvas` 文件夹里的**全部内容**上传到仓库根目录
3. 仓库 Settings → Pages → Source 选 `main` 分支 / 根目录 → Save
4. 等一两分钟，得到网址 `https://你的用户名.github.io/lifecanvas/`

> 提示：若部署在子路径下，`index.html` 与 `manifest.webmanifest` 里的相对路径（`./`）已按子路径兼容，无需改动。

---

## 四、安装到 iPhone（添加主屏幕）

1. iPhone 用 **Safari** 打开你的网址（首次需联网，加载一次）
2. 点底部 **分享按钮** → **添加到主屏幕** → 添加
3. 主屏幕出现「具象画」图标，点开即全屏运行
4. **之后完全离线可用**——飞行模式下也能打开、阅读、记录

> ⚠️ 必须通过"添加到主屏幕"使用（不要直接在 Safari 里用），
> 这样 iOS 才不会清理离线数据（Safari 会清理未安装的 PWA 缓存）。

## 五、AI 生图工坊（v0.2 新增）

> 生成只发生在"创建期"（需联网），生成完的图片永久保存在本机，日常使用依然完全离线。

**第一步 · 配置 API Key（约 3 分钟，一次性）**
1. 打开 **cloud.siliconflow.com**，用手机号注册（国内直接访问）
2. 左侧「API 密钥」→ 创建密钥 → 复制（sk- 开头）
3. 打开 app → 设置 → 「AI 生图配置」→ 粘贴 → 保存 → 点「测试连接」确认成功
   - 新用户送免费额度；`FLUX.1-schnell` 模型**完全免费**；`Qwen-Image-Edit` 按张计费（额度内可体验）

**第二步 · 生成未来形象**
- 形象页 → 生成工坊：选模型（推荐 `Qwen-Image-Edit`，可传真实照片做参考，生成像你）→ 可加一句补充描述 → 点「✨ 生成 4 张」
- 候选图出现后点「保存并设为主形象」→ 首页每天第一眼就是未来的你

**第三步 · 生成愿景场景**
- 愿景页 → 选分类 + 写一句话愿景 → 点「✨ AI 生成场景图」
- 会自动用「未来形象」做参考图——场景里的人就是你

**模型说明**

| 模型 | 特点 | 费用 |
|------|------|------|
| Qwen-Image-Edit | 支持参考图（图生图），保形象最像你 | 计费（额度内免费体验） |
| Qwen-Image | 纯文生图，画质高 | 计费 |
| FLUX.1-schnell | 免费、快速，纯文生图 | 完全免费 |

> 注意：生成需联网；API Key 只存本机，仅在生成时发送给服务商（这是生图必要的传输，除此之外应用不发任何请求）。

## 六、日常使用流程（建议）

1. **第一天 · 创建形象**：形象页填写形象卡 → 上传 1-3 张真实照片 →（可选）上传榜样参考图并调融合比例 → 点"复制提示词"
2. **生图（需联网，一次性）**：把提示词粘贴到 即梦 / Midjourney / 通义万相 等工具，生成你的未来形象图 → 把结果图"导入"进形象页 → **设为主形象**
3. **添加愿景场景**：想象理想生活（家、爱好角落、父母、孩子……），生成或收集图片导入，配一句愿景文字
4. **每天**：打开就是今日正念和愿望回看 → 完成小目标去「记录」页打卡领奖励 → 睡前写三件感恩
5. **每周/每月**：在「设置」页导出备份（见下），防丢数据

## 七、隐私与离线保障

- 日常使用 **100% 离线**：除"生图"环节（你手动在别处生成）外，应用不发出任何网络请求
- 所有数据存于本机：结构化数据（IndexedDB）+ 图片（OPFS）
- 无账号、无 Cookie、无统计、无任何第三方 SDK
- Service Worker 预缓存全部应用壳 → 断网秒开

---

## 八、口令加密

- 设置：设置页 → 口令加密 → 启用（**口令请务必牢记，丢失无法找回**）
- 启用后「愿望」与「记录」加密存储（AES-256-GCM + PBKDF2 10 万次迭代），解锁前不可见
- 加密需要安全上下文：通过 `http://localhost` 或 `https://` 访问才可用（部署到 GitHub Pages 后即满足）

---

## 九、备份与恢复（重要）

数据只在本机，**请定期备份**：

1. **导出备份包（.lvpack）**：全部内容打包成一个文件，可存到 iCloud 文件 / 电脑 / 网盘
2. **导出 HTML 快照**：所有愿景图 + 文字内嵌进一个 HTML 文件，**任何浏览器双击离线即读**——飞机上没装工具也能看，终极兜底
3. **恢复**：设置页 → 从备份恢复（会覆盖当前数据，恢复前请确认）

换手机 / 清浏览器前，务必先导出备份。

## 十、文件结构

```
lifecanvas/
├── index.html            # 应用壳（单页）
├── css/style.css         # 样式（暖色杂志风）
├── js/
│   ├── util.js           # 通用工具 + 极简 ZIP 打包/解包
│   ├── crypto.js         # 口令加密（AES-GCM + PBKDF2）
│   ├── db.js             # IndexedDB + OPFS 存储层
│   ├── data.js           # 默认正念库、分类、提示词模板
│   ├── backup.js         # 备份/恢复/快照
│   ├── gen.js            # v0.2 生图工坊（硅基流动 API 客户端）
│   └── app.js            # 主逻辑（六模块 + 生图）
├── sw.js                 # 离线缓存（Service Worker）
├── manifest.webmanifest  # PWA 清单
├── icons/                # 应用图标（512/192/180）
└── tools/
    ├── gen-icons.mjs     # 重新生成图标：node tools/gen-icons.mjs
    └── smoke.cjs         # 冒烟测试：node tools/smoke.cjs
```

## 十一、开发提示

- 修改代码后**重新部署**时，请把 `sw.js` 里的 `CACHE` 版本号 +1（如 `lifecanvas-v2`），否则旧缓存不更新
- 图标可用 `node tools/gen-icons.mjs` 重新生成
- 冒烟测试：`node tools/smoke.cjs`
